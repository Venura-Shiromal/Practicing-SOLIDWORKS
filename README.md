# SolidWorks Practice Models

A collection of 3D parts I modeled while practicing **SolidWorks**. All files are saved as `.SLDPRT` (part files).

---

## What's Included

- Various mechanical components and practice parts
- Models created to learn sketching, extrusions, revolves, lofts, fillets and patterns.

---

## Tools Used

- **SolidWorks 2025** 

---

## How to View

1. Open any `.SLDPRT` file in SolidWorks 2025.
2. Use **FeatureManager** to explore the modeling steps.

---

## Notes

- Parts are for practice purposes only – not optimized for manufacturing.
- Feel free to use them as reference for your own learning.
